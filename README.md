# Action Chess

## Voraussetzungen

- Python 3.12 oder neuer

## Einmalige Installation

```powershell
py -3.12 -m pip install --user "pygame>=2.6,<3"
```

## Spiel starten

```powershell
py -3.12 Chess.py
```

Die Abhängigkeiten werden über die globale Python-Installation deines Benutzerkontos verwendet. Eine virtuelle Python-Umgebung gehört nicht in dieses Repository.
